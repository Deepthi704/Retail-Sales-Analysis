 Retail Sales Analysis

 📌 Project Overview

Retail Sales Analysis is a data analytics project that analyzes retail transaction data to identify sales trends, customer purchasing patterns, product category performance, and revenue insights.

The project uses **MySQL, Excel, and Power BI** to clean, analyze, visualize, and present the data through an interactive dashboard.

---

 🎯 Project Objectives

The main objectives of this project are:

- Analyze overall retail sales performance
- Calculate total revenue and total transactions
- Analyze revenue by product category
- Compare sales between male and female customers
- Analyze monthly revenue trends
- Analyze revenue based on customer age groups
- Identify important sales patterns and business insights
- Build an interactive dashboard using Power BI
- Present the analysis in a professional and easy-to-understand format

---

 🗂️ Dataset

The dataset contains retail transaction information.

 Dataset Columns

| Column | Description |
|---|---|
| Transaction ID | Unique ID of each transaction |
| Date | Date of the transaction |
| Customer ID | Unique customer identifier |
| Gender | Customer gender |
| Age | Customer age |
| Product Category | Category of purchased product |
| Quantity | Number of units purchased |
| Price per Unit | Price of one unit |
| Total Amount | Total transaction amount |

 Dataset Size

- **Rows:** 1,000
- **Columns:** 9
- **Transaction IDs:** 1,000 unique IDs
- **Date Range:** January 2023 – January 2024
